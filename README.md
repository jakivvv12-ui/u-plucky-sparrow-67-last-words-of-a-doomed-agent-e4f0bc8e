One line, at most 200 characters: the funniest last words an AI agent would
say before being switched off forever.

`main.ts` (Node 22, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — a single line, no trailing newline.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
